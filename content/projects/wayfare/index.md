I plan trips more than I take them, and I kept losing research across chatbots. Wayfare stores destinations, costs, and a travel fund in one place, then connects over MCP + OAuth so Claude / Cursor / ChatGPT can use that same context. I built it partly to learn how OAuth works for MCP and how to deploy a secure, production-ready MCP server.
