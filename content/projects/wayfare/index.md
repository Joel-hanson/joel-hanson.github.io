I plan trips more than I take them, and I kept losing research across chatbots. Wayfare stores destinations, costs, and a travel fund in one place, then connects over MCP with OAuth so Claude, Cursor, and ChatGPT can use that same context. I also built it to learn how OAuth works for MCP and how to deploy a production MCP server.
