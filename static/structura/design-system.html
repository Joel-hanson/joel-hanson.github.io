Rules for agents

Also in AGENTS.md

  • Edit prototypes/tokens.css first; screens consume it.
  • Status colour is the loudest signal — don’t mute badges.
  • No Inter / Roboto / purple gradients / cream+terracotta AI defaults.
  • Don’t put WhatsApp green chrome on client or firm pages.
  • Avoid metric-card strips; prefer next action + real work lists.
  • When Figma MCP is available: screenshot Patterns from these mockups — don’t redesign from scratch.
